# Glossary (plain words)

**Sitrep** — military shorthand for "situation report": what's happening right now.

**OSINT** — "open-source intelligence". Fancy phrase for "paying close attention to public information" — news, government feeds, satellite bulletins. Journalists, researchers and governments all do this.

**Feed** — a place where a source publishes updates (a news site's latest stories, a quake list, a weather alert list).

**Source** — where a piece of information came from (e.g. NASA, USGS, the BBC). Sitrep always shows the source label.

**Event** — one thing on the map: an earthquake, a wildfire, a flood warning, a conflict headline tied to a place.

**Hotspot / convergence** — a place where several *different* sources report at once. Agreement between independent sources is a strong signal.

**Tension** — our word for "lots of negative news coverage here". It measures media attention, not danger.

**Severity** — the urgency color on an event, chosen by simple rules (words like "killed", "tsunami warning", quake magnitudes). A hint, not a verdict.

**Brief** — the summary panel on the right. Written by an AI when the site owner enables it; otherwise built by ranking the biggest items.

**Watch / watchlist** — a saved keyword filter in the news feed, so "red sea" is one tap away.

**Wire** — the scrolling news column on the left.

**Ticker** — the strip of headlines along the bottom.

**UTC / Z time** — the clock in the top bar. Intelligence work runs on one shared world clock so nobody argues about time zones.

**MapLibre** — the free map technology used to draw the world map.

**Open source / AGPL** — the code is public; anyone may run, copy, or improve it, as long as shared versions also share their code.
