## Key facts an agent must know

1. **Provenance is mandatory** — quote `sourceLabel` + `url` when citing an item.
2. **`tone` absent ≠ neutral** — it means the signal is event-derived, not measured.
3. **`mode: deterministic` briefs are summaries of the event feed** — generated by rules, not an LLM; `generatedAt` is the real generation time.
4. **`unpolled` source = not configured** (missing key), not an error.
5. **429s are real** — respect `Retry-After`; don't retry storms.
6. Root index for LLMs: `/llms.txt` in the repo root.
